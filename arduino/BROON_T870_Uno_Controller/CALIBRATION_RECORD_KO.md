# BROON T870 Uno 교정 기록

이 기록은 출력 잠금 `BROON_ENABLE_ACTUATOR_OUTPUTS` 및 조향 교정 잠금
`BROON_STEERING_CALIBRATION_CONFIRMED`를 **0에서 변경하기 전에**
완성·검토·서명해야 한다. 현재 두 잠금은 모두 `0`이며, 이 양식에 빈 값이
남아 있으면 어떤 잠금도 변경하지 않는다.

측정값을 추정하지 않는다. 모든 칸을 현재 T870에서 직접 측정하고 서명한다.

## 공통 안전 전제

- 24 V 물리 차단장치가 즉시 접근 가능한 상태에서 작업한다.
- Uno, 수신기, 모터 드라이버의 신호 GND를 공통 접지하고, 각 전원 경로의
  퓨즈를 확인한다.
- 엔코더 입력 전압이 Uno 입력 허용 범위인지 계측으로 확인한다. 확신이 없으면
  연결하지 않는다.
- 출력·방향·교정 시험은 바퀴를 지면에서 완전히 띄운 상태에서만 수행한다.
- CAN은 RC/ROS 기반 차량 제어가 검증될 때까지 의도적으로 보류한다. 후륜 구동은
  D6/D7을 사용하며, D10/D11은 현재 모터 출력에 사용하지 않는다.
- 후륜 속도 피드백은 없다. 속도/엔코더 피드백은 전륜 D2/D3 엔코더만 사용한다.

## 전사 및 잠금 변경 점검

1. 측정·서명된 기록을 `ControllerConfig.h` 값으로 전사한다.
2. 정방향과 역방향의 10회전 카운트는 **부호가 반대**인지와
   `abs(count)/10`의 절대 크기가 일관적인지를 비교한다. 부호를 포함한 두 수를
   단순 평균하거나 역방향의 음수 부호 때문에 불일치로 숨기지 않는다.
3. RC 조향·스로틀·AUX의 최소/중앙/최대는 `ControllerConfig.h`의
   `kRcSteerCalibration`, `kRcThrottleCalibration`, `kRcAuxCalibration`에 각각
   따로 전사한다. `kRcTimeoutMs`의 현재 기본값은 100 ms이지만 현재 T870 시험 결과와
   승인 없이 바꾸지 않는다. AUX 범위 안에 ROS/RC 임계값이 올바른 순서로
   들어오는지도 독립 검토한다.
4. A1 throttle-cut 활성 펄스가 `kRcStopThresholdUs`보다 낮고, A1 신호가 끊겨도
   RC 원격정지가 활성화되는지 확인한다.
5. RC 원격정지, 출력 잠금, 조향 교정 잠금, 유효 구성, 중립 대기, 타임아웃을
   리프트 휠 상태에서 모두 재확인한다. 이 문서의 완성만으로 출력이 허가되지는
   않는다.
